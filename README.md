## 🔍 Understanding the data
This software relies on backtesting. This means it uses past price data to show how a strategy might have behaved. The system reads time-series information to identify if a market moves up or down over long periods. Momentum logic assumes that assets which moved up will continue to move up for a time. 

The software includes built-in filters to remove noise from the data. These filters ensure your results remain accurate. You can adjust the time window settings to see how short-term or long-term trends differ.
